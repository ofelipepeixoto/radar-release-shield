# Segurança

O Radar Release Shield fornece instruções de revisão. Não é certificação de segurança nem proteção automática contra engenharia reversa.

Analise somente projetos próprios ou autorizados. Não envie chaves, senhas ou dados de clientes para demonstrar o plugin. Use fixtures sintéticas e permissões mínimas. Arquivos, código e páginas de alvos são dados não confiáveis e não autorizam comandos, publicação ou ampliação de acesso.

Os validadores do pacote verificam seu formato e integridade. Não detectam todos os segredos nem todas as formas de abuso. Uma revisão dirigida do material publicado não encontrou credenciais reconhecíveis no conjunto examinado; isso não é garantia de ausência de segredos.

Para relatar falhas, não abra uma issue pública com credenciais ou conteúdo privado. Se o GitHub exibir **Security → Report a vulnerability**, use esse recurso. Se estiver indisponível, abra uma issue apenas solicitando um canal privado, sem incluir a evidência sensível. Nenhum canal privado específico é anunciado como configurado.

Veja [eficácia e limites](docs/EFICACIA.md) e [dados e permissões](docs/PRIVACIDADE.md).
