# Instalar no ChatGPT

## Com o Plugin Creator

1. [Baixe radar-release-shield-v0.1.1.zip](https://github.com/ofelipepeixoto/radar-release-shield/raw/refs/heads/main/dist/radar-release-shield-v0.1.1.zip). Não use o ZIP geral do repositório.
2. No ChatGPT, abra **Plugins**, procure **Plugin Creator** e instale, se necessário.
3. Inicie uma conversa com ele e anexe o ZIP baixado.
4. Envie o pedido abaixo.
5. Abra o link devolvido. Instale ou selecione o plugin, conforme a opção apresentada.
6. Para trabalhar com repositórios, conclua a conexão do seu GitHub e escolha o acesso necessário.

```text
Crie na minha conta uma cópia privada deste plugin a partir do ZIP anexado.
Preserve as seis skills e suas referências. Confira os componentes salvos
e me entregue o link do plugin. Não crie servidor ou hospedagem.
```

## Se houver envio direto no seu espaço de trabalho

Com permissão de proprietário ou administrador: **Console de administração → Plugins → Adicionar → Fazer upload de plugin**. Envie o mesmo ZIP.

A disponibilidade varia por conta, função e interface. Sem essa opção, use o caminho do Plugin Creator quando disponível ou consulte seu administrador. Instalar não autoriza o GitHub automaticamente.

Fonte: [guia oficial da OpenAI, consultado em 01/11/2026](https://help.openai.com/pt-br/articles/20001256-plugins-in-chatgpt).

## Confirmar o resultado

Selecione Radar Release Shield numa conversa e use a fixture do [guia de uso](USAR.md). O comportamento observado precisa distinguir diagnóstico, hipótese e teste realmente executado. Não envie credenciais para confirmar a instalação.

O link da cópia privada do autor não é uma instalação universal. O código público e o ZIP permitem criar outra cópia. Publicação no diretório da OpenAI é um processo separado; este pacote com vínculo de app não é um arquivo preparado para submissão pública ao diretório.
